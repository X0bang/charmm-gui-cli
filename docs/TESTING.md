# 测试与验收

本页说明当前测试方法和证据边界。版本历史及过往验收记录集中在 [CHANGELOG](../CHANGELOG.md)；认证协议调研见 [RESEARCH](../RESEARCH.md)，转换实验见 [CONVERSION](CONVERSION.md)。

## 本地回归

在安装依赖的 Python 环境、源码根目录运行：

```bash
python -m pip install '.[chem]'
CHARMM_GUI_CLI_LANG=en python -m unittest discover -s tests -q
CHARMM_GUI_CLI_LANG=zh python -m unittest discover -s tests -q
```

测试使用合成结构、模拟 HTTP 和独立临时目录，不要求真实账户，也不创建官网模型。发布包不含私有 test-dataset；依赖私有结构的测试明确 skip，而不是伪造通过。部分测试需要 pip/venv 等本地工具，安装依赖本身需要网络或完整的本地 wheelhouse。

最近正式发行的本地英文/Python 3.13、中文/Python 3.10 各通过 1089 项；公开源码包通过 1089 项，其中 25 项按私有数据等前提明确跳过。独立 wheel 的 115 项专项测试和源码包一键安装、跨目录版本/帮助/doctor 检查也通过。具体发行记录以 CHANGELOG 和对应提交的 CI 为准，不把测试数量作为后续版本的固定保证。

## CI 与发行验收

GitHub CI 的 Ubuntu 22.04/macOS × Python 3.10/3.13 四组环境分别运行中英文测试和打包检查。Python 3.14 及真实 macOS 远端建模未完成专项验收。

发布前另从白名单生成源码包及 wheel，在新目录检查解包字节、wheel RECORD、SHA256SUMS 和实际安装。正式附件发布后重新下载核验，确认 main/tag/版本一致、附件齐全，并用上一版更新器检查新版可见。发布资产不覆盖已正式发布版本，也不夹带会话、账户、私有结构、模型或内部审计记录。

```bash
python scripts/build_release.py --out /path/to/new-release-directory
```

构建器拒绝覆盖已有附件；应选择新的输出目录。构建成功不等于已推送标签或发布 GitHub Release。

## 真实模型验收

最新独立蛋白/SDF 对照和经过删水、altloc、MSE 及明确 HIE/HSE 状态处理的 PDBQT 变体，均已取得最终原始归档，通过坐标/拓扑、脂质膜叶、离子、配体相对位姿和 GROMACS 输入编译核验。两者分别含 370471/370567 个原子、78667/78699 个 TIP3；修复变体的 15 个 MET 保留，明确请求的 HSE 在最终 PSF 中具有正确的类型、电荷和 NE2–HE2 连接。这些是实际模型证据，不是 mock 表单或仅源任务残基名。

两者均为 POPC/POPE 混合膜：上叶 350/150、下叶 338/145，144 POT/145 CLA，构建记录为 KCl 0.10 M；独立水数比估算约 0.10159/0.10155 M，不冒充盒体积浓度。配体各有 96 个原子、97 个 PSF 键；共同蛋白拟合后的配体重原子 RMSD 约 0.273/0.125 Å。归档、PDB/PSF、编译日志和 TPR 哈希均逐项核对，并保留各 3 条质量审阅警告。

同一扫描的第二个浓度条件尚未完成最终归档验收；已确认复用了同一准备源及原建膜 ID，没有重新上传。不能把第一项通过写成整批 2/2 通过。私人输入和运行记录不随源码分发。

## 尚未证明的范围

- 真实 OS 凭据库和跨十二小时续期、真实 macOS 建模/通知、按链 Gly/Pro 多链新建模及全部故障注入仍有未完成的实测门槛。
- 主链几何断裂会被拒绝；显式接受片段并自动添加断端补丁尚未提供。独立 check 目录还没有整合到任务管理。
- 本地力场转换仍是离线实验。原子对齐或单点能量通过不能替代完整参数、位置/二面角约束和不同体系验收；默认仍运行官网转换。
- 输入检查和 grompp 不执行本地最小化、平衡或生产 MD。研究者仍需审核质子化、力场适用性、配体参数、膜取向、HMR/时间步长和警告，并按自己的运行环境完成平衡。
